## Overview

V1 product plan for Atreides — the core spatial organization experience.

This plan assumes `setup.md` is complete: Neon database is running, Better Auth is working, Next.js backend serves API routes, and the Electron renderer can talk to the backend.

**The core loop:** User opens the app → sees their root board → sees nodes on the board → can double-click a node to zoom into a linked board → can navigate back. Everything is spatial. Everything is on a board.

## High Level Goals

- [ ] Custom Atreides node type that displays title, description, and a visual indicator when it links to a board
- [ ] Board loading: fetch a board's nodes and edges from the backend, render them in React Flow
- [ ] Node CRUD: create nodes by double-clicking empty canvas, edit via click, drag to reposition (auto-save position)
- [ ] Edge CRUD: connect nodes by dragging handles, edges persist to backend
- [ ] Board navigation: double-click a "portal" node to zoom into its linked board, breadcrumb trail to go back
- [ ] onClick actions: URL opens in browser, CLI runs in Electron, board navigates to board
- [ ] Auth UI: simple sign-in / sign-up screen before the board loads
- [ ] Clean, minimal dark UI — the boards are the star, not the chrome

## Implementation Plan

### Architecture Decision: How board navigation works

**Options:**

1. **URL-based routing** (e.g. `/board/:id`) — each board is a route, browser back/forward works
2. **In-memory board stack** — push/pop boards in React state, animate transitions within a single React Flow instance
3. **Swap ReactFlow instances** — unmount one, mount another per board

**Recommendation: Option 2 — In-memory board stack.** URL routing adds complexity (need a router, need to handle deep links, etc.) and doesn't buy much for v1. The Minecraft-like spatial experience is better served by smooth in-canvas transitions. Keep a stack of `{ boardId, viewport }` in state. When you "enter" a board, push. When you go back, pop. Animate the viewport transition using React Flow's `setViewport` with a duration. If URL routing is needed later, it can be layered on top.

### Architecture Decision: How node editing works

**Options:**

1. **Inline editing** — double-click node text to edit in-place
2. **Side panel** — click node, panel slides in from the right with form fields
3. **Modal dialog** — click node, modal overlays

**Recommendation: Option 2 — Side panel.** It keeps the canvas visible (you can still see spatial context), doesn't block the view like a modal, and is more natural for a spatial tool. The panel shows title, description, onClick config, and a "Link to board" button.

### Architecture Decision: When to save node positions

**Options:**

1. **Save on every drag event** — too many API calls
2. **Save on drag end** — one call per drag, but user might drag multiple nodes before "settling"
3. **Debounced auto-save** — save 1 second after the last position change

**Recommendation: Option 3 — Debounced auto-save.** Batch all position changes within a 1-second window into a single API call. This handles rapid repositioning gracefully. React Flow's `onNodesChange` fires with every drag tick — collect the changes, debounce, then send the final positions.

```typescript
  id: string
  sourceNodeId: string
  targetBoardId: string

  targetY: number | null

export interface Edge {
  id: string
  boardId: string
  sourceNodeId: string
  targetNodeId: string
  label: string | null
}

// What the API returns for a full board
export interface BoardData {
  board: Board
  nodes: AtreidesNode[]
  edges: Edge[]
  nodeLinks: NodeLink[]
}

// React Flow node data shape
export interface AtreidesNodeData {
  title: string
  description: string | null
  onClick: OnClickAction | null
```

**Notes:**
- We name it `AtreidesNode` not `Node` to avoid collision with React Flow's `Node` type.
- `AtreidesNodeData` is what gets passed into `data` on React Flow nodes. It's a projection of the DB model plus the link info.

#### 1.2 Board data hook

**File:** `src/hooks/useBoard.ts`

```typescript
import { useState, useEffect, useCallback } from 'react'
import { api } from '@/lib/api'
import type { BoardData, AtreidesNode, AtreidesNodeData } from '@/types'
import type { Node, Edge } from '@xyflow/react'

// Converts API data into React Flow nodes and edges
function toFlowNodes(data: BoardData): Node<AtreidesNodeData>[] {
  const linkMap = new Map(data.nodeLinks.map(l => [l.sourceNodeId, l]))

  return data.nodes
    .filter(n => !n.archived)
    .map(n => {
      const link = linkMap.get(n.id)
      return {
        id: n.id,
        type: 'atreides',
        position: { x: n.positionX, y: n.positionY },
        data: {
          title: n.title,
          description: n.description,
          onClick: n.onClick,
          hasLink: !!link,
          linkedBoardId: link?.targetBoardId ?? null,
          dbId: n.id,
        },
      }
    })
}

function toFlowEdges(data: BoardData): Edge[] {
  return data.edges.map(e => ({
    id: e.id,
    source: e.sourceNodeId,
    target: e.targetNodeId,
    label: e.label ?? undefined,
  }))
}

export function useBoard(boardId: string | null) {
  const [boardData, setBoardData] = useState<BoardData | null>(null)
  const [flowNodes, setFlowNodes] = useState<Node<AtreidesNodeData>[]>([])
  const [flowEdges, setFlowEdges] = useState<Edge[]>([])
  const [loading, setLoading] = useState(true)
  const [error, setError] = useState<string | null>(null)

  const load = useCallback(async (id: string) => {
    setLoading(true)
    setError(null)
    try {
      const data = await api.getBoard(id) as BoardData
      setBoardData(data)
      setFlowNodes(toFlowNodes(data))
      setFlowEdges(toFlowEdges(data))
    } catch (err) {
      setError(err instanceof Error ? err.message : 'Failed to load board')
    } finally {
      setLoading(false)
    }
  }, [])

  useEffect(() => {
    if (boardId) load(boardId)
  }, [boardId, load])

  return { boardData, flowNodes, flowEdges, loading, error, reload: () => boardId && load(boardId) }
}
```

```typescript

  ReactFlow,
  Background,
  Controls,
  MiniMap,
  useNodesState,
  useEdgesState,
  addEdge,
  useReactFlow,
  type OnConnect,
  type OnNodesChange,
  type NodeMouseHandler,
} from '@xyflow/react'
import '@xyflow/react/dist/style.css'

import AtreidesNode from './AtreidesNode'
import BoardBreadcrumbs from './BoardBreadcrumbs'
import NodeEditor from './NodeEditor'
import CreateNodeDialog from './CreateNodeDialog'
import { useBoard } from '@/hooks/useBoard'
import { useBoardNavigation } from '@/hooks/useBoardNavigation'
import { useAutoSave } from '@/hooks/useAutoSave'
import { useNodeActions } from '@/hooks/useNodeActions'
import { api } from '@/lib/api'
import type { AtreidesNodeData } from '@/types'

const nodeTypes = { atreides: AtreidesNode }

export default function BoardCanvas() {
  const { currentBoardId, boardStack, pushBoard, popToIndex } = useBoardNavigation()
  const { boardData, flowNodes, flowEdges, loading, error, reload } = useBoard(currentBoardId)
  const [nodes, setNodes, onNodesChange] = useNodesState(flowNodes)
  const [edges, setEdges, onEdgesChange] = useEdgesState(flowEdges)
  const { setViewport } = useReactFlow()
  const { schedulePositionSave } = useAutoSave()
  const { executeAction } = useNodeActions({ pushBoard })

  // State for UI panels
  const [selectedNodeId, setSelectedNodeId] = useState<string | null>(null)
  const [createDialogPos, setCreateDialogPos] = useState<{ x: number; y: number } | null>(null)

  // Sync flowNodes/flowEdges when board data changes
  useEffect(() => {
    setNodes(flowNodes)
    setEdges(flowEdges)
  }, [flowNodes, flowEdges])

  // Handle edge creation
  const onConnect: OnConnect = useCallback(async (params) => {
    setEdges(eds => addEdge(params, eds))
    if (currentBoardId && params.source && params.target) {
      await api.createEdge({
        boardId: currentBoardId,
        sourceNodeId: params.source,
        targetNodeId: params.target,
      })
    }
  }, [currentBoardId, setEdges])

  // Handle node position changes (auto-save)
  const handleNodesChange: OnNodesChange = useCallback((changes) => {
    onNodesChange(changes)
    // Filter for position changes that are done dragging
    const positionChanges = changes.filter(c => c.type === 'position' && c.dragging === false)
    if (positionChanges.length > 0) {
      schedulePositionSave(nodes)
    }
  }, [onNodesChange, schedulePositionSave, nodes])

  // Double-click node → navigate to linked board or execute onClick
  const onNodeDoubleClick: NodeMouseHandler = useCallback((_, node) => {
    const data = node.data as AtreidesNodeData
    if (data.hasLink && data.linkedBoardId) {
      pushBoard(data.linkedBoardId)
    } else if (data.onClick) {
      executeAction(data.onClick)
    }
  }, [pushBoard, executeAction])

  // Single-click node → open editor
  const onNodeClick: NodeMouseHandler = useCallback((_, node) => {
    setSelectedNodeId(node.id)
  }, [])

  // Double-click canvas → create node
  const onPaneDoubleClick = useCallback((event: React.MouseEvent) => {
    // Convert screen coords to flow coords
    const bounds = (event.target as HTMLElement).closest('.react-flow')?.getBoundingClientRect()
    if (!bounds) return
    // Use the reactflow instance to project screen to flow coords
    // (handled via screenToFlowPosition in the actual component)
    setCreateDialogPos({ x: event.clientX, y: event.clientY })
  }, [])

  if (loading) return <div className="board-loading">Loading board...</div>
  if (error) return <div className="board-error">{error}</div>

  return (
    <div style={{ width: '100vw', height: '100vh' }}>
      <BoardBreadcrumbs stack={boardStack} onNavigate={popToIndex} />

      <ReactFlow
        nodes={nodes}
        edges={edges}
        onNodesChange={handleNodesChange}
        onEdgesChange={onEdgesChange}
        onConnect={onConnect}
        onNodeDoubleClick={onNodeDoubleClick}
        onNodeClick={onNodeClick}
        onDoubleClick={onPaneDoubleClick}
        nodeTypes={nodeTypes}
        fitView
        snapToGrid
        snapGrid={[20, 20]}
      >
        <Background gap={20} size={1} color="#313244" />
        <Controls />
        <MiniMap
          nodeColor={() => '#89b4fa'}
          maskColor="rgba(0,0,0,0.7)"
        />
      </ReactFlow>

      {selectedNodeId && (
        <NodeEditor
          nodeId={selectedNodeId}
          boardId={currentBoardId!}
          onClose={() => setSelectedNodeId(null)}
          onSave={reload}
        />
      )}

      {createDialogPos && (
        <CreateNodeDialog
          boardId={currentBoardId!}
          screenPosition={createDialogPos}
          onClose={() => setCreateDialogPos(null)}
          onCreated={reload}
        />
      )}
    </div>
  )
}
```

#### 3.1 Board navigation hook

**File:** `src/hooks/useBoardNavigation.ts`

```typescript
import { useState, useCallback } from 'react'
import { useReactFlow } from '@xyflow/react'

interface BoardStackEntry {
  boardId: string
  boardTitle: string
  viewport: { x: number; y: number; zoom: number }
}

export function useBoardNavigation() {
  const [boardStack, setBoardStack] = useState<BoardStackEntry[]>([])
  const [currentBoardId, setCurrentBoardId] = useState<string | null>(null)
  const { getViewport, setViewport } = useReactFlow()

  // Initialize with root board
  const initWithRootBoard = useCallback((rootBoardId: string, rootTitle: string) => {
    setCurrentBoardId(rootBoardId)
    setBoardStack([{ boardId: rootBoardId, boardTitle: rootTitle, viewport: { x: 0, y: 0, zoom: 1 } }])
  }, [])

  // Navigate into a linked board
  const pushBoard = useCallback((boardId: string, boardTitle?: string) => {
    const currentViewport = getViewport()
    setBoardStack(prev => {
      const updated = [...prev]
      // Save current viewport to the top of stack
      if (updated.length > 0) {
        updated[updated.length - 1] = {
          ...updated[updated.length - 1],
          viewport: currentViewport,
        }
      }
      return [...updated, { boardId, boardTitle: boardTitle ?? 'Board', viewport: { x: 0, y: 0, zoom: 1 } }]
    })
    setCurrentBoardId(boardId)

    // Animate zoom-in transition
    setViewport({ x: 0, y: 0, zoom: 1 }, { duration: 300 })
  }, [getViewport, setViewport])

  // Navigate back to a specific point in the stack
  const popToIndex = useCallback((index: number) => {
    setBoardStack(prev => {
      const sliced = prev.slice(0, index + 1)
      const target = sliced[sliced.length - 1]
      setCurrentBoardId(target.boardId)

      // Restore saved viewport with animation
      setViewport(target.viewport, { duration: 300 })

      return sliced
    })
  }, [setViewport])

  return {
    currentBoardId,
    boardStack,
    initWithRootBoard,
    pushBoard,
    popToIndex,
  }
}
```

```typescript
          <button onClick={handleSave} disabled={saving}>
            {saving ? 'Saving...' : 'Save'}
          </button>

          {!hasLink && (
            <button onClick={handleLinkToNewBoard} className="node-editor__link-btn">
              Link to New Board
            </button>
          )}

          <button onClick={handleDelete} className="node-editor__delete-btn">
            Delete Node
          </button>
        </div>
      </div>
    </div>
  )
}
```

**Notes:**
- The NodeEditor in this skeleton needs to be initialized with the node's current data. In practice, pass the node data from the parent component or read it from a shared state/context. Don't make a separate API call for data you already have.
- The "Link to New Board" flow: creates a board, then creates a node_link. Two API calls. Could be one if we add a compound endpoint, but keep it simple for v1.

```typescript
import type { OnClickAction } from '@/types'

const isElectron = typeof window !== 'undefined' && !!window.ipcRenderer

interface Options {
  pushBoard: (boardId: string) => void
}

export function useNodeActions({ pushBoard }: Options) {
  const executeAction = (action: OnClickAction) => {
    switch (action.type) {
      case 'url':
        if (isElectron) {
          window.ipcRenderer.invoke('open-external', action.value)
        } else {
          window.open(action.value, '_blank')
        }
        break

      case 'cli':
        if (isElectron) {
          window.ipcRenderer.invoke('run-cli', action.value)
        } else {
          console.warn('CLI actions are only available in the desktop app')
        }
        break

      case 'board':
        pushBoard(action.boardId)
        break
    }
  }

  return { executeAction }
}
```

### Phase 7: Auto-save hook

**File:** `src/hooks/useAutoSave.ts`

```typescript
import { useRef, useCallback } from 'react'
import { api } from '@/lib/api'
import type { Node } from '@xyflow/react'

export function useAutoSave() {
  const timeoutRef = useRef<ReturnType<typeof setTimeout> | null>(null)

  const schedulePositionSave = useCallback((nodes: Node[]) => {
    if (timeoutRef.current) clearTimeout(timeoutRef.current)

    timeoutRef.current = setTimeout(async () => {
      // Save all node positions in parallel
      await Promise.all(
        nodes.map(node =>
          api.updateNode(node.id, {
            positionX: node.position.x,
            positionY: node.position.y,
          })
        )
      )
    }, 1000)
  }, [])

  return { schedulePositionSave }
}
```

**Notes:**
- This fires individual PATCH requests per node. For v1 this is fine. If it becomes a bottleneck (many nodes being dragged), add a batch endpoint later (`PATCH /api/boards/:id/nodes/positions` with an array).
- The 1-second debounce means: user drags nodes around, positions save 1 second after they stop. No save-on-every-frame. No explicit "save" button.

### Backend API endpoints (Phase 1-7 supporting routes)

These are the Next.js API routes. Each is a standard App Router route handler.

#### GET `/api/boards/:id`

Returns the full board with its nodes, edges, and node_links:

```typescript
// server/src/app/api/boards/[id]/route.ts
import { db } from '@/lib/db'
import { boards, nodes, edges, nodeLinks } from '@/db/schema'
import { eq } from 'drizzle-orm'
import { NextResponse } from 'next/server'

export async function GET(_: Request, { params }: { params: { id: string } }) {
  const { id } = params

  const [board] = await db.select().from(boards).where(eq(boards.id, id))
  if (!board) return NextResponse.json({ error: 'Not found' }, { status: 404 })

  const boardNodes = await db.select().from(nodes).where(eq(nodes.boardId, id))
  const boardEdges = await db.select().from(edges).where(eq(edges.boardId, id))

  // Get node_links for all nodes on this board
  const nodeIds = boardNodes.map(n => n.id)
  const links = nodeIds.length > 0
    ? await db.select().from(nodeLinks).where(
        // Use inArray for multiple IDs
        sql`${nodeLinks.sourceNodeId} = ANY(${nodeIds})`
      )
    : []

  return NextResponse.json({ board, nodes: boardNodes, edges: boardEdges, nodeLinks: links })
}
```

#### POST `/api/boards/:id/nodes`

Create a node on a board:

```typescript
export async function POST(request: Request, { params }: { params: { id: string } }) {
  const { title, positionX, positionY } = await request.json()

  const [node] = await db.insert(nodes).values({
    boardId: params.id,
    title,
    positionX,
    positionY,
  }).returning()

  return NextResponse.json(node, { status: 201 })
}
```

#### PATCH `/api/nodes/:id`

Update a node's fields:

```typescript
export async function PATCH(request: Request, { params }: { params: { id: string } }) {
  const updates = await request.json()

  const [node] = await db.update(nodes)
    .set({ ...updates, updatedAt: new Date() })
    .where(eq(nodes.id, params.id))
    .returning()

  return NextResponse.json(node)
}
```

**Notes:**
- These are simplified. In the real implementation, validate inputs and ensure the user owns the board (check `boards.ownerId` against the session user).
- The `PATCH` endpoint accepts partial updates. Don't blindly spread user input into the query — whitelist allowed fields (`title`, `description`, `positionX`, `positionY`, `onClick`).

### Summary: Interaction model

| Action | What happens |
|---|---|
| Double-click empty canvas | CreateNodeDialog appears at cursor — type title, hit Enter |
| Single-click a node | NodeEditor panel opens on the right |
| Double-click a portal node | Zoom-transition into the linked board |
| Double-click a non-portal node with onClick | Execute the onClick action (open URL, run CLI) |
| Drag a node | Node moves, position auto-saves after 1s |
| Drag from node handle to another node | Edge created, persisted to DB |
| Click breadcrumb | Zoom-transition back to that board |
| Refresh the page | Everything reloads from the database |
